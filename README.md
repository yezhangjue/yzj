# yzj

## Python 程序设计 实验六：程序控制结构

| 文件 | 任务说明 |
| --- | --- |
| 猜数游戏.py | 任务1：系统在指定范围内生成随机数，提示用户猜测并给出“太大了 / 太小了 / 猜对了”提示；猜对提前结束，次数用完则公布正确答案。 |
| 成绩统计.py | 任务2：输入 10 个成绩（输入 -1 提前结束），统计“优、良、中、及格、不及格”各等级人数。 |
| 水仙花数.py | 任务3：求 10000 以内的水仙花数（自幂数，各位数字的 n 次幂之和等于该数，n 为位数）。 |

### 运行方式

```bash
python 猜数游戏.py
python 成绩统计.py
python 水仙花数.py
```

## Python 程序设计 集合 / 字典 / 内置函数练习

| 文件 | 任务说明 |
| --- | --- |
| 集合并集.py | 任务(1)：输入包含若干集合的列表，用 reduce() 函数和 lambda 表达式求这些集合的并集。 |
| 等比数列求和.py | 任务(2)：输入首项、公比（不等于 1 且小于 36 的正整数）和自然数 n，输出等比数列前 n 项之和；关键步骤使用内置函数 int()。 |
| 出现次数最多字符.py | 任务(3)：输入一个字符串，用字典统计各字符出现次数，输出出现次数最多的字符及其次数。 |
| 字母数字频次统计.py | 任务(4)：输入任意长字符串，统计所有字母和数字的频次，结果以字典保存并输出。 |

### 运行方式

```bash
python 集合并集.py
python 等比数列求和.py
python 出现次数最多字符.py
python 字母数字频次统计.py
```
